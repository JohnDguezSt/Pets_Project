# EmptyState

**Propósito:** cuando una lista o sección no tiene contenido, decir qué falta y ofrecer una sola acción. Ej.: «Agrega a tu primera mascota».

| Propiedad | Tipo |
| --- | --- |
| `title` | texto (obligatorio) |
| `description` | texto opcional |
| `action` | un elemento, normalmente un Button |
| `headingLevel` | `2` (por defecto) · `3` |

**Reglas:** sin ilustración obligatoria (doc. 20 §9); nunca contenido de ejemplo ni actividad simulada; tono directo y sin culpa.

**Accesibilidad:** el título es un encabezado real; elige `headingLevel` según la jerarquía de la página.
